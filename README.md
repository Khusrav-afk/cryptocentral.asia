Одностраничник на чистом HTML/CSS/JS. Ничего не нужно собирать.

```

│   ├── muslim-shelf.jpg    # запасное
```

## ⚠️ Перед деплоем

**1. Скопировать отзывы.** Папка `img/otz/` пустая. На старом сайте (cryptocentral.asia/kombo/) лежат файлы:
- `1.jfif ... 15.jfif`
- `16.jpg ... 20.jpg`

Скопируйте все 20 файлов в `img/otz/` — карусель сразу заработает.

**2. Проверить ссылки на оплату.** В `index.html` ссылки `buy/?price=...&tarif=...` оставлены такие же, как на старом сайте. Если бэкенд обработки оплат остался прежним — всё заработает.

**3. Гугл-форма анкеты** — та же, что была: `docs.google.com/forms/d/.../viewform`. Менять не нужно.

**4. Дата старта потока** — везде стоит **7 июня (сб)**. Если поток сдвинется, ищите в `index.html`:
- блок hero: `<b>07 Июня (сб)</b>`
- блок «Старт»: `СТАРТ <em>07 Июня (сб)</em>`
- метаописание

**5. Дата окончания акции** — `3 июня`. Меняется в двух местах:
- `index.html` — `<div class="val">3 июня</div>` (в .promo-date)
- `js/main.js` — функция `getDeadline()`: `new Date(Date.UTC(year, 5, 3, ...))` (5 = июнь, 3 = число).

## Деплой

Просто залейте всю папку в корень (или подкаталог) вашего сервера. Никакого билда, никаких зависимостей — только статика.

## Браузерная совместимость

Chrome / Safari / Firefox / Edge последних 2 лет. Использует современные CSS-фичи (Grid, custom properties, `aspect-ratio`).
